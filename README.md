# dev-learning

My path to becoming a full-stack developer: daily exercises, notes, and mini projects, following a structured roadmap.

## Structure

- `week1/day1`: development environment (terminal, VS Code, Node, Git)
- `week1/day2`: git fundamentals (init, add, commit, status, log, etc.) and first push
- `week1/day3`: branching, merging, feature-branch workflow, and first pull request
